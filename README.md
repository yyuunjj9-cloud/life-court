# ⚖ 오늘의 생활법원 (life-court)

> 당신의 사소한 억울함을 엄숙하게 심리합니다.

점심 메뉴 결정 지연부터 메시지 읽씹까지, 일상의 사소한 분쟁을 **가상의 법정**에서 엄숙하게(그러나 공정하지 않게) 심리해 주는 오락용 웹 앱입니다. 사연을 접수하면 고소장·판결문·항소심 판결문 같은 그럴듯한 법률 문서가 생성되고, 이미지로 저장해 공유할 수 있습니다.

**본 서비스는 오락 목적의 가상 콘텐츠이며, 실제 법률 자문·법률 판단 또는 실제 판결이 아닙니다.**

## 주요 기능

| 기능 | 설명 |
|---|---|
| 사건 접수 | 사연(10~300자) → 사건 유형(회사생활·인간관계·식사·메신저·일상) → 피고와의 관계 → 심각성(1~5) → 판결 성향(관대함·공정함·엄벌주의) 순서로 접수 |
| 대응 방식 선택 | **고소장**(피해자 본인) / **고발장**(정의로운 제3자) / **내용증명**(재판 전 경고장) 중 선택 |
| 내용증명 | 시정 요구 + 3일 이행 기한 + "미이행 시 생활법원 접수 예정" 경고. 회신이 없으면 재판으로 전환 |
| 심리 진행 | 6단계 심리 기록이 실시간 콘솔 연출로 진행 |
| 판결문 | 사건번호·가상 죄명·주문·판결 이유·생활 개선 권고·최종 판결(무죄~괘씸죄 가중 유죄)이 담긴 제1심 판결문 |
| 항소 | 항소심 재판부가 원심 파기(무죄) 또는 항소 기각(원심 유지)을 결정 |
| 맞고소 | 판결 후 피고 측이 맞고소장을 제출. 원심이 관대했을수록 맞고소가 인용되기 쉬움 |
| 문서 저장 | 판결문·항소심 판결문·고소/고발장·내용증명·맞고소장을 PNG/JPG 이미지로 다운로드 |

## 판결 생성 원리

모든 문서는 **템플릿/규칙 기반**으로 생성됩니다(실제 법령·판례와 무관, LLM 미사용).

- 사연 텍스트를 해시해 시드 난수로 사용 → **같은 입력이면 항상 같은 판결**
- 판결 수위는 심각성(1~5), 성향 보정(관대 −1 / 공정 0 / 엄벌 +1), 사연의 반복·고의 및 사과·피해 회복 표현, 사연 시드에 따른 제한적 보정(−1~+1)으로 결정됩니다. 기본 설정에서도 사연에 따라 훈방·조건부 유죄·유죄 등이 달라집니다.
- 죄목은 구체적인 행위 표현을 우선해 전체 유형에서 찾고, 선택한 유형은 보조 기준으로 사용합니다. 단순 단어 조각만 일치하거나 근거가 부족하면 무관한 죄목을 무작위로 붙이지 않고 일반 분쟁으로 처리합니다. 이 경우 유죄 처분을 제한합니다.
- 판결문·고소장·내용증명은 같은 사건 선택 로직을 사용합니다. 규칙 기반이므로 부정 표현·복합 사연의 의미를 완전히 이해하지는 못합니다.

## 개발 검증

```bash
npm test
npm run typecheck
npm run build
```

push·PR마다 GitHub Actions가 위 검사와 실제 Postgres 동시 요청 검증을 자동 실행합니다. 운영 DB와 격리된 컨테이너를 사용합니다. 로컬 Postgres 테스트는 `TEST_DATABASE_URL`을 지정하고 `npm run test:postgres`로 실행합니다. 자세한 구성과 안전장치는 [docs/ci.md](docs/ci.md)를 참고하세요.

사건 분류, 문서 간 죄목 일치, 판결 다양성, 재현성 및 심각성·성향에 따른 판결 수위 순서를 검증합니다. 새 규칙은 새로 생성하는 사건에 적용되며, DB에 저장된 판결은 변경하지 않습니다. 구형 `/shared` 링크는 현재 규칙으로 재생성하므로 결과가 달라질 수 있습니다.

## 아키텍처 — 3티어

```
frontend (Next.js)  ──HTTP──▶  backend (Express API)  ──SQL──▶  db (Postgres/Supabase)
화면·연출·이미지 저장           판결/문서 생성, 사건번호 발급        사건 기록 보관
```

- **frontend** — Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 + 커스텀 법정 테마 · html-to-image(문서 이미지 저장). 문서는 API 응답을 표시만 합니다.
- **backend** — Express 5 · TypeScript. 판결·고소장·내용증명·맞고소장 생성기와 사건번호 시퀀스가 모두 여기에 있습니다. `DATABASE_URL`이 없으면 인메모리 저장소로 동작해 DB 없이도 로컬 개발이 가능합니다.
- **db** — Postgres(권장: Supabase) `cases` 테이블. 사연·선택값·생성된 문서(JSONB)를 보관합니다.

## 실행 방법

```bash
# 1) 의존성 설치
cd frontend && npm install
cd ../backend && npm install

# 2) (선택) DB 연결 — 없으면 인메모리로 동작
cp backend/.env.example backend/.env   # DATABASE_URL 입력
psql "$DATABASE_URL" -f db/schema.sql

# 3) 실행 (루트에서)
npm run dev:backend    # API 서버 :4000
npm run dev:frontend   # 웹 앱   :3000
```

모바일에서는 전체 화면, 데스크톱에서는 중앙 폰 프레임으로 표시됩니다.

├─ src/domain/          # 판결·문서 생성기 (템플릿/규칙 기반, 시드 난수)

## 이용 안내

1. 본 서비스는 오락 목적의 가상 콘텐츠이며, 실제 법률 자문·법률 판단 또는 실제 판결이 아닙니다.
2. 입력하신 내용은 판결 생성을 위해 서버로 전송되어 사건 기록으로 보관되며, 그 외의 용도로 사용되거나 제3자에게 공유되지 않습니다.
3. 타인의 개인정보, 불법 행위, 혐오 표현 등 부적절한 내용은 입력할 수 없습니다.
4. 모든 판결 결과는 템플릿/규칙 기반으로 생성되며, 실제 법령이나 판례와 무관합니다.
