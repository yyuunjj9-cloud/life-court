# ⚖ 오늘의 생활법원 (life-court)

> 당신의 사소한 억울함을 엄숙하게 심리합니다.

점심 메뉴 결정 지연부터 메시지 읽씹까지, 일상의 사소한 분쟁을 **가상의 법정**에서 엄숙하게(그러나 공정하지 않게) 심리해 주는 오락용 웹 앱입니다. 사연을 접수하면 고소장·판결문·항소심 판결문 같은 그럴듯한 법률 문서가 생성되고, 이미지로 저장해 공유할 수 있습니다.

**본 서비스는 오락 목적의 가상 콘텐츠이며, 실제 법률 자문·법률 판단 또는 실제 판결이 아닙니다.**

## 주요 기능

| 기능 | 설명 |
|---|---|
| 사건 접수 | 사연(10~300자) → 사건 유형(회사생활·인간관계·식사·메신저·일상) → 피고와의 관계 → 심각성(1~5) → 판결 성향(관대함·공정함·엄벌주의) 순서로 접수 |
| 대응 방식 선택 | **고소장**(피해자 본인) / **고발장**(정의로운 제3자) / **내용증명**(재판 전 경고장) 중 선택 |
| 내용증명 | 시정 요구 + 3일 이행 기한 + "미이행 시 생활법원 접수 예정" 경고. 회신이 없으면 재판으로 전환 |
| 심리 진행 | 6단계 심리 기록이 실시간 콘솔 연출로 진행 |
| 판결문 | 사건번호·가상 죄명·주문·판결 이유·생활 개선 권고·최종 판결(무죄~괘씸죄 가중 유죄)이 담긴 제1심 판결문 |
| 항소 | 항소심 재판부가 원심 파기(무죄) 또는 항소 기각(원심 유지)을 결정 |
| 맞고소 | 판결 후 피고 측이 맞고소장을 제출. 원심이 관대했을수록 맞고소가 인용되기 쉬움 |
| 문서 저장 | 판결문·항소심 판결문·고소/고발장·내용증명·맞고소장을 PNG/JPG 이미지로 다운로드 |

## 판결 생성 원리

모든 문서는 **템플릿/규칙 기반**으로 생성됩니다(실제 법령·판례와 무관, LLM 미사용).

- 사연 텍스트를 해시해 시드 난수로 사용 → **같은 입력이면 항상 같은 판결**
- 판결 수위 = 심각성(1~5) + 성향 보정(관대 −1 / 공정 0 / 엄벌 +1) → 무죄 → 훈방 조치 → 조건부 유죄 → 유죄 → 괘씸죄 가중 유죄
- 죄명·주문·권고는 사건 유형별 템플릿 풀에서 선택되며, 판결 이유에는 사용자의 사연이 인용됨

## 기술 스택

- **Next.js 16** (App Router, 정적 프리렌더) · **React 19** · **TypeScript**
- **Tailwind CSS 4** + 커스텀 CSS(고풍 법정 테마, 외부 리소스 없음)
- **html-to-image** — 판결문 이미지 저장
- 상태 관리: React Context + sessionStorage(사연)/localStorage(사건번호 시퀀스)

백엔드·데이터베이스 없는 **프론트엔드 단독 구조**입니다. 판결 생성이 규칙 기반이라 서버 연산이 필요 없고, 입력 내용을 외부에 저장하지 않는다는 안내 제2조에 따라 모든 데이터는 브라우저 안에만 머뭅니다.

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (기본 3000 포트)
npm run build      # 프로덕션 빌드
npm run start      # 프로덕션 서버
npm run typecheck  # 타입 검사
```

모바일에서는 전체 화면, 데스크톱에서는 중앙 폰 프레임으로 표시됩니다.

## 프로젝트 구조

```
src/
├─ app/                 # 화면 (App Router)
│  ├─ page.tsx          #   랜딩
│  ├─ intake/           #   접수: story(사연) → type(유형/관계) → tone(심각성/성향) → filing(대응 방식)
│  ├─ complaint/        #   고소장·고발장
│  ├─ demand/           #   내용증명
│  ├─ trial/            #   심리 진행 연출
│  ├─ verdict/          #   제1심 판결문
│  ├─ appeal/           #   항소심 판결문
│  ├─ countersuit/      #   맞고소장
│  ├─ save/             #   문서 이미지 저장
│  ├─ received/         #   접수 완료
│  └─ notice/           #   안내(고지)
├─ components/          # 공용 UI (상단 바, 진행 표시, 문서 뷰)
├─ domain/              # 판결·문서 생성기 (순수 함수, 템플릿/규칙 기반)
└─ store/               # 사건 상태 저장소 (Context + 브라우저 스토리지)

mockups/                # 화면 목업 (PNG 10종)
mobile.html             # 초기 정적 프로토타입 (구현의 원본 디자인)
```

## 이용 안내

1. 본 서비스는 오락 목적의 가상 콘텐츠이며, 실제 법률 자문·법률 판단 또는 실제 판결이 아닙니다.
2. 입력하신 내용은 시스템(브라우저) 내에서만 사용되며, 외부에 저장되거나 공유되지 않습니다.
3. 타인의 개인정보, 불법 행위, 혐오 표현 등 부적절한 내용은 입력할 수 없습니다.
4. 모든 판결 결과는 템플릿/규칙 기반으로 생성되며, 실제 법령이나 판례와 무관합니다.
