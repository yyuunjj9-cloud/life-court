# 개발 검증 기록 — 2026-11-02

## 자동 검증

- `cd backend && npm test`: 51개 테스트 통과.
- 사연 36개: 5개 유형, 유형을 잘못 선택한 사연, 부정·오해 표현, 분류 근거 부족 사례. 실제 사용자 기록이 아닌 합성 예문이다.
- 판결·고소장·내용증명 간 사건 일치, 반복 사실 없는 사연의 상습 표현 제거, 기본 설정의 결과 다양성, 동일 입력 재현성, 심각성·성향의 단조성.
- 메모리 저장소 번호 예약 100건, 답변서 동시 제출 100건.
- 실제 로컬 HTTP API 접수 30건 동시 요청: 번호·토큰 중복 없음. 답변서 30건 동시 요청: 1건 201, 29건 409.
- 공유 토큰으로 접수자 행동 실행 불가, 접수자 토큰으로 공유 조회·답변 실행 불가, 공유 응답에 입력 원문·접수자 토큰 없음.
- SVG 효과 4종, 한 화면에서 SVG 그라데이션 식별자 중복 없음.
- 백엔드 TypeScript 빌드, 프론트 Next.js 프로덕션 빌드 통과.

## 브라우저 확인

설치된 headless Chromium을 사용했다. 로컬 메모리 서버 외의 사건 기록은 만들지 않았다.

- 375×812, 390×844: 접수 → 심리 → 판결 → 항소 → 맞고소 → PNG/JPG 저장 버튼 실행. 가로 넘침 없음.
- 항소 인용 시 Sustained!, 항소 기각 시 Overruled!, 맞고소 기각·각하 시 Case dismissed! 확인. 맞고소 인용 시 기존 맞고소 연출 유지.
- 영문 효과는 화면에만 표시되며 저장용 `.vdoc` 안에 들어가지 않는다.
- 저장 화면 직접 진입 시 상태 복원 전에 홈으로 이동하던 문제 수정 및 재검증.
- 새 공유 링크에서 답변 제출 후 새로고침해도 답변 유지.
- 1280×900: 데스크톱 중앙 프레임 및 가로 넘침 없음.
- OG PNG 생성 및 시각 확인. 새 한글 문구의 글리프 누락을 전체 나눔명조 글꼴로 교체해 해결. OFL 라이선스 동봉.
- 스크린샷과 로컬 테스트 데이터는 Git 제외 대상인 `.gstack/`에만 보관.

## 검증 한계

- Safari/WebKit 실기기 및 카카오톡 실제 앱, 모바일 OS 공유 시트는 검증하지 못했다. Chromium의 모바일 크기 테스트를 실기기 검증으로 간주하지 않는다.
- Postgres의 동시 요청 테스트는 로컬 DB가 없어 실행하지 않았다. 운영 저장소는 단일 UPSERT로 번호를 예약하고 조건부 UPDATE로 답변을 접수한다. 운영 마이그레이션은 배포 시 초기화/health로 확인한다.
- 기존 해시 공유 링크와 접수자 토큰 없는 과거 사건의 추가 처분은 보안 정책에 따라 제한된다. 저장된 판결은 변경하지 않는다.
- 금칙어 차단·거절 문구는 논의 단계이며 이번 변경에서 새 필터를 추가하지 않았다.
