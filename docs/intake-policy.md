# 진술 접수 기준

규칙의 단일 원본은 `backend/src/domain/moderation.ts`다. 외부 AI·유료 API를 사용하지 않는다.

- 명확한 욕설·상대 또는 집단 비하 표현을 제한한다. 인용된 욕설도 직접 재현하지 않고 ‘욕설을 했다’처럼 행동으로 서술하도록 안내한다.
- 전화번호·이메일·주민등록번호로 보이는 형식을 제한한다. 이름·주소 등 모든 개인정보를 자동으로 식별하는 기능은 아니다.
- 직접적인 위해·위협 표현을 제한한다. ‘죽을 먹었다’ 등 일상 표현과 구분한다.
- 일부 띄어쓰기·구두점·보이지 않는 문자·전각 문자 변형을 정규화한다. 규칙 기반이라 우회와 오탐을 완전히 막을 수는 없다. 후보 규칙을 늘릴 때는 정상 사연 테스트도 함께 추가한다.
- 작성 화면의 ‘다음’에서 검사하며, 사건 접수·구형 공유 재현·내용증명 API에서도 같은 기준을 강제한다. 차단 시 HTTP 422와 분류·수정 안내만 반환하고, 원문은 저장하거나 오류 응답에 되돌리지 않는다. 차단된 사건에는 사건번호를 발급하지 않는다.
- 사용자에게는 작은 황갈색 `Inadmissible!` 도장과 ‘진술 보완 요청’, 구체적인 수정 안내를 표시한다. 입력은 유지하며 사용자를 비난하는 문구를 쓰지 않는다.
- 기존 저장 사건을 소급 삭제·수정하지 않는다. 필터는 새 접수 및 새로 생성하는 문서에 적용한다.
